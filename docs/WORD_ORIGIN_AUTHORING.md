# 単語語源データの作成基準

`data/word_roots.json` と `data/word_origins.json` は、単語カードの意味を思い出すための表示用データです。学習進捗、音声パス、4択の出題順や選択肢には使いません。

## A/B/C の判定

| 型 | 判定 | 付けるもの |
| --- | --- | --- |
| A | 接辞＋語根に分解でき、現在の中心義を思い出す助けになる | `parts`、`root`、`gloss`、`derivation` |
| B | 借用語・比喩など、分解は効かないが由来の一行が有効 | `derivation`。必要なら `chain` と `source` |
| C | 分解がこじつけになる、または語根を安全に特定できない | 何も付けず、`data/word_origin_excluded.json` に語根別で理由を記録 |

## 記述ルール

- キーは `data/lemmas.json` 適用後の小文字の原形にする。
- A型の `parts` は接頭辞・語根・接尾辞の順で並べ、構成要素自身の意味を書く。
- 接辞が多義の場合も辞書の `gloss` をそのまま貼らず、その語で採用した意味を1つ書く。
- `suffix` の `parts[].form` と `affixes` のキーは `-ion` のように先頭ハイフン付きにし、綴りの包含確認ではハイフンを外す。
- `parts[].form` は（接尾辞のハイフンを除き）原形に実際に現れる綴りにする。似ているだけの文字列を語根にしない。
- A型の `gloss` は語根単位の短い訳にし、原形の `vocab_*.json` の `meaning` に含まれる16文字以内の文字列にする（現在カードには表示せず、検査用の要約として使う）。
- `derivation` の矢印の後ろは、`vocab_*.json` の `meaning` にある中心義と結び付ける。
- 同じ語根の仲間語はカードに表示しない（語根パネルは廃止）。`root` は検査と将来の逆引き用に必ず付ける。
- 迷った語は件数を埋めるためにA/Bへ入れず、C型にする。

## 語源チェーン（`chain`）

熟語の核心イメージと同じ視覚構成で、語源から現在の意味までを段階的に示したい語には、B型へ任意の `chain` を追加する。B型は「既存の語根・接辞辞書を使ったA型分解ではない」というデータ上の分類であり、チェーン表示の有無を表すものではない。

```json
{
  "type": "B",
  "chain": [
    { "term": "prae-", "gloss": "前もって" },
    { "term": "monere", "gloss": "前もって警告する" },
    { "gloss": "予感、虫の知らせ" }
  ],
  "derivation": "前もって知らせることから → 予感、虫の知らせ",
  "source": "https://www.etymonline.com/word/premonition",
  "sources": [
    "https://www.etymonline.com/word/premonition",
    "https://www.merriam-webster.com/dictionary/premonition",
    "https://www.collinsdictionary.com/dictionary/english/premonition"
  ]
}
```

- `chain` は2〜5段にし、各段に短い `gloss` を付ける。
- `term` は歴史的な形・語根・元の語など、学習に必要な場合だけ付ける。最終段は `term` と導出矢印を付けず、現在の中心義だけにする。
- 最終段は語彙データの `meaning` と揃える。`derivation` の矢印の後ろにも同じ中心義を置き、既存のデータ検査を通す。
- `source` は後方互換のために残す主参照先、`sources` は照合した2サイト以上のURL一覧として記録する。細かな起源が不確かな語は、チェーン内や `note` で不確かさを明示し、断定しない。
- 語源の深い段階まで複数サイトが一致しない場合は、共通して確認できる言語・語形までに止める。推測の語根でチェーンを長くしない。
- 実装では`flashWordOrigin`が`.originChain`を生成し、熟語と共通の`.coreChain` CSSを使う。意味の直下・例文の前という3部構成は変えない。

## 単発語根（段階5以降）

- 語根はアプリ内で複数語に使えることを要件にしない。要件は、その語根を示すと現在の中心義を思い出せることだけにする。
- 語根の `origin` にはラテン語・ギリシャ語の原形を必ず書く。原形を確認できない語根は登録しない。
- 語根の `note` には、その語根を持つ英語の別の語を1つ以上挙げる。アプリに未収録の語でもよい。
- 分解しても中心義が導けない語は、仲間語が増やせそうでもB型にする。

## パイロット

段階0では `equivocate`、`evocative`、`liaison` を登録し、A型のチップ・導出行とB型の由来一行を確認する。今回のパイロットでは英検1級模試第6回の84語に`chain`を付け、熟語と同じ連鎖カードで確認する。辞書を空にしても通常カードが起動することを合格条件に含める。
