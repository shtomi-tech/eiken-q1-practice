# 単語語源データの作成基準

`data/word_roots.json` と `data/word_origins.json` は、単語カードの意味を思い出すための表示用データです。学習進捗、音声パス、4択の出題順や選択肢には使いません。

## A/B/C の判定

| 型 | 判定 | 付けるもの |
| --- | --- | --- |
| A | 接辞＋語根に分解でき、現在の中心義を思い出す助けになる | `parts`、`root`、`derivation` |
| B | 借用語・比喩など、分解は効かないが由来の一行が有効 | `derivation` のみ |
| C | 分解がこじつけになる、または語根を安全に特定できない | 何も付けず、検査側の `cReasons` に理由を記録 |

## 記述ルール

- キーは `data/lemmas.json` 適用後の小文字の原形にする。
- A型の `parts` は接頭辞・語根・接尾辞の順で並べ、構成要素自身の意味を書く。
- `parts[].form` は原形に実際に現れる綴りにする。似ているだけの文字列を語根にしない。
- `derivation` の矢印の後ろは、`vocab_*.json` の `meaning` にある中心義と結び付ける。
- 同じ語根の仲間語は手書きせず、`root` の逆引きで表示する。訳は既存の語彙データから取得する。
- 迷った語は件数を埋めるためにA/Bへ入れず、C型にする。

## パイロット

段階0では `equivocate`、`evocative`、`liaison` を登録し、A型のチップ・語根パネル・B型の由来一行を確認する。辞書を空にしても通常カードが起動することを合格条件に含める。
