## 追補（レビュー指摘3件の反映）

修正後レビューで残った3点を直した。設問・語彙の件数、正答位置の分布、`particle` 件数は変えていない。

| 対象 | 直した内容 | 理由 |
| --- | --- | --- |
| mock-4 Q13 | 設問文を「画家が絵の隅をわざと塗り残した」文脈へ差し替え | 旧文の `not by accident` が `on purpose` の言い換えで、語を知らなくても解けた。末尾の「規則を恒久的に維持する」も誤答排除のためだけの節だった |
| mock-4 `hang up` | `particleSense` を `raise` → `complete`、連鎖を「受話器を掛ける → 終わりまで → 受話器を掛けて通話を終える」へ。語源も同じ向きに直した | 旧連鎖の最終語義「電話を掛けて切る」が矛盾して読めた。`up` は「上へ」より完了の含みが近い |
| mock-3 `check out` | 連鎖を「確認する → 選び出して → 対象を選び出して確かめる」へ | `particleSense` の `reserve`（pick out / single out）と連鎖の「外へ取り出して」が結び付いていなかった |
| mock-2 `find out` | `particleSense` を `spread` → `produce`、連鎖を「見つける → 表に出して → 隠れた情報を表に出して突き止める」へ | `spread`（write out / map out）は「広げて示す」で、隠れた情報が表に出る動きと合わない |

見送った点（記録として残す）:

- ダミーの `museum` / `garden` / `park` / `folder` は文脈上あからさまに不成立で消去が容易。正答一意性は保たれるため据え置いた。
- mock-4 Q1 の正答 `board` は `bulletin board` が2語で熟語バケットへ入るための妥協。
- mock-2 Q11 は `figure out the meaning` が成立しかけるが、`in a dictionary` が排除しているため据え置いた。
- 語彙40件の品詞構成（名詞20 / 形容詞12 / 動詞8 / 副詞0）は今回の対象外。次に語彙を差し替えるときに副詞・動詞を増やす。
